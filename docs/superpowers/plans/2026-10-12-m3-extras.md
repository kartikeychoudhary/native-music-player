# Aurora M3 — Extras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the M3 extras to Aurora:
- **DSP (processed mode only):** a 10-band EQ with presets, ReplayGain (track/album/off), and crossfade with smart skip, each controllable from Settings and visible in the signal path.
- **Lyrics:** synced (LRC, enhanced word timing, SYLT) and plain lyrics from embedded tags and sidecar `.lrc` files.
- **Visuals:** an expanded Now Playing view (large art, album-palette background, Lyrics / Queue / Signal path / Credits tabs) with a live spectrum visualizer, and an optional accent tint from album art.
- **Windows:** a 340×110 always-on-top mini-player and a tray icon with transport controls.

**Architecture:**
- **ReplayGain** is a per-track gain applied in the decode thread's `ProcessChain` (it's fixed for a track).
- **EQ** runs in the realtime output callback (`RingSource::fill`), so slider changes are heard immediately instead of after the 2 s decode-ahead buffer.
  - The player publishes settings through a lock-free seqlock (`EqShared`).
  - Each stream designs its own biquads for its sample rate.
- **Crossfade** mixes two `ProcessChain`s in the decode thread.
  - `ProcessChain` splits into `render` (to f64 at the output rate) and `encode` (to device bytes with dither).
  - The player adds a `Crossfade` state that renders the outgoing and incoming tracks, mixes them with an equal-power curve, and places the incoming track's marker at the start of the overlap.
- **Spectrum:**
  - The output callback copies a mono mix into a tap ring.
  - An analyzer thread computes a 2048-point FFT at 30 fps.
  - The engine sends 64-byte frames as binary stdout frames (`0x1E` + u32 LE length + payload).
  - Electron main decodes them and forwards them only to windows that subscribed.
- **DSP settings** are engine-owned (`dsp.json` in the data dir, spec §2 "Rust owns DSP") and broadcast with a new `dsp.changed` event.
- **Lyrics** live in the `library` crate (spec §3.1 lists lyrics under `library/`) behind a `lyrics.get` method.
- **Electron main** gains a window manager:
  - the main window plus the mini-player;
  - events fan out to every window;
  - a tray.
- **The renderer:**
  - renders the mini-player from the same bundle at `#/mini`, without the app layout;
  - adds `/now-playing`.

**Tech Stack:**
- Existing and unchanged: Rust 1.99.0 (edition 2024), Electron 44.7.0, React 19.3, Zustand 5, TanStack Router 1.170.42, Vitest 5, Playwright 1.64.
- New direct Rust dependency: `realfft = "3.5.0"` in `engine-core`. It's already in `Cargo.lock` through `rubato`, so this adds no new code to the build.
- No new npm packages. The visualizer uses a plain `<canvas>`, and the tray icon is drawn from code.

**Spec:** `docs/superpowers/specs/2026-10-10-aurora-music-player-design.md`. This plan implements **Milestone 3** from §9; executors read both. Earlier rulings are in `docs/superpowers/m1-execution-notes.md` and `docs/superpowers/m2-execution-notes.md`.

## Global Constraints

### Protocol and engine
- **Protocol version:** bump to `PROTOCOL_VERSION = 3`. The protocol gains:
  - signal-path stage kinds `replaygain`, `eq` and `crossfade`;
  - the `dsp.*`, `lyrics.get` and `viz.*` methods;
  - the `dsp.changed` event;
  - binary spectrum frames.
- **Protocol types:** every new wire type lives in `protocol` with `ts-rs` and is regenerated into `shared/protocol/`. Generated files are committed, and the CI staleness gate applies.
- **Output thread rule (unchanged, now load-bearing):** no allocation, locks, I/O or logging in output callbacks. The EQ, the fade and the spectrum tap all run there:
  - the EQ reads its settings through a seqlock;
  - the tap pushes into a pre-allocated `rtrb` ring and drops samples when it's full.
- **stdout:** only `rpc/writer.rs` writes to it. Binary frames are `0x1E`, then a `u32` little-endian payload length, then the payload. The payload's first byte is the frame kind: `1` is spectrum, followed by 64 `u8` bins. JSON lines never start with `0x1E` (spec §4.1).
- **Bit-perfect mode (spec §3.5):**
  - ReplayGain, EQ, crossfade and software volume are **disabled**, and their signal-path stages read `bypassed (bit-perfect)`.
  - The bytes reaching the device stay identical to the source. The existing bit-perfect tests must keep passing with every DSP feature switched on.
- **DSP values (spec §3.6):**
  - **EQ:** 10 bands at 31, 62, 125, 250, 500, 1k, 2k, 4k, 8k and 16k Hz. Each band is ±12 dB, built from RBJ peaking biquads with Q = 1.41. The preamp is ±12 dB.
  - **Automatic headroom:** the applied preamp is lowered by the largest positive band gain.
  - **Built-in presets:** Flat, Warm, Bass, Vocal, Bright and Loudness. User presets are stored by name and can't reuse a built-in name.
  - **ReplayGain:** modes `track`, `album` and `off`.
    - Values come from `REPLAYGAIN_*` tags, or `R128_*` tags on Opus (Q7.8 values, +5 dB to reach the ReplayGain reference). `iTunNORM` is ignored.
    - **Peak protection:** the applied gain is limited so that the peak stays ≤ −0.1 dBFS. A missing peak counts as 1.0.
    - **Fallback:** `track` mode falls back to album values, and `album` mode to track values.
  - **Crossfade:** 0–12 s, where 0 means off. It uses an equal-power curve (gain_out = cos(t·π/2), gain_in = sin(t·π/2)).
    - It applies only to automatic advances.
    - **Smart skip:** never crossfade between consecutive tracks of the same album played in order. "In order" means the same `album_id`, and either the same disc with track + 1, or the next disc's track 1.
- **Spectrum (spec §3.6):** a 2048-point FFT with a Hann window and 64 log-spaced bins (30 Hz up to 16 kHz or Nyquist, whichever is lower), sent at 30 fps.
  - Each bin is the peak magnitude in its band, mapped from −80…0 dBFS to 0…255.
  - It's computed only while at least one window is subscribed (`viz.subscribe` / `viz.unsubscribe`).
- **Lyrics (spec §3.9):**
  - **Sources:** a sidecar `<basename>.lrc` next to the file, embedded `USLT`/`©lyr`/`LYRICS`/`UNSYNCEDLYRICS` text, and ID3 `SYLT` (millisecond timestamps only).
  - **Shape:** results are `{ synced, lines: [{ tMs?, text, words? }] }`.
  - **Priority:** the first *synced* source in the order sidecar → SYLT → embedded text wins. If none is synced, the first plain source wins.

### Scope
- **Deferred to M4 (spec §9):** packaging, auto-update, signing and multi-target CI builds.
- **Out of scope for v1 (spec §10):** parametric EQ, online lyrics, and a light theme. They stay out.
- **Rulings made in this plan** (an executor follows them; a reviewer checks against them):
  - **R1, EQ placement:** the EQ is applied after the crossfade mix, in the output callback. The spec orders the chain ReplayGain → preamp → EQ → crossfade → volume. EQ and crossfade are both linear, so EQ(a)+EQ(b) = EQ(a+b): the result is the same, with one filter state instead of two, and EQ changes are heard instantly.
  - **R2, crossfade scope:** crossfade applies only when a track ends by itself. Manual Next/Prev/double-click keep M2's 10 ms fade. Repeat-one replays (the same entry again) are never crossfaded.
  - **R3, ReplayGain coverage:** ReplayGain values come from the library, so files opened from outside the library (`queue.setPaths`) play at unity gain. Their signal path reads `no ReplayGain data`.
  - **R4, DSP storage:** DSP settings and user presets persist in `<data-dir>/dsp.json`. Without `--data-dir` they live in memory for the session.
  - **R5, frame kind byte:** spectrum frames carry a leading kind byte (`1`), so the frame channel can carry other payloads later. The payload is 65 bytes.
  - **R6, Now Playing tabs:** the Queue and Signal path tabs embed the existing Queue and Signal views' contents.

## Review Focus

These are inputs the spec implies but no feature test naturally exercises. Each line is pinned by the named test.

1. **Crossfade around tracks shorter than the fade, and a seek or queue edit during the overlap.**
   - **Expected:** the overlap shrinks to half the shorter track. No audio is dropped or duplicated, nothing hangs, and a seek in the overlap plays only the track being seeked.
   - **Tests:** Task 5 `crossfade_shrinks_for_short_tracks`, `seek_during_crossfade_plays_one_track`, `removing_the_incoming_track_during_crossfade_resyncs`.
2. **Every DSP feature switched on while in bit-perfect mode.**
   - **Expected:** the device still receives the source bytes unchanged, and switching back to processed mode brings EQ, ReplayGain and crossfade back.
   - **Tests:** Task 3 `bit_perfect_ignores_eq`, Task 4 `bit_perfect_ignores_replay_gain`, Task 5 `bit_perfect_never_crossfades`.
3. **Real-world LRC files:**
   - a UTF-8 BOM, CRLF line endings or Latin-1 bytes;
   - several timestamps on one line, an `[offset:]` tag, metadata tags;
   - malformed timestamps, and lines out of order.
   - **Expected:** they parse into sorted lines, bad tags are skipped, and nothing panics.
   - **Tests:** Task 7 `lrc_handles_real_world_quirks`, `lrc_with_no_timestamps_is_plain`.
4. **Spectrum subscriptions when a window closes or is hidden, or when the engine restarts.**
   - **Expected:** the engine stops analysing when no visible window wants frames, and resumes after a restart if one still does.
   - **Tests:** Task 9 `viz_refcount_tracks_windows_and_engine_restarts`, Task 14 `spectrum_unsubscribes_when_hidden_or_unmounted`.
5. **A mini-player position saved on a monitor that's since been unplugged, and tray actions while the main window is hidden.**
   - **Expected:** the mini-player opens on a visible display, and Show/Hide and transport actions work with no window visible.
   - **Tests:** Task 10 `mini_bounds_are_clamped_to_a_visible_display`, Task 11 `tray_menu_reflects_state_and_drives_actions`.

```rust
//! DSP settings (spec §3.6, §4.3 `dsp.*`). The engine owns and persists them.
use serde::{Deserialize, Serialize};
use ts_rs::TS;

#[derive(Serialize, Deserialize, TS, Clone, Copy, Debug, PartialEq, Eq, Default)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub enum ReplayGainMode { #[default] Off, Track, Album }

#[derive(Serialize, Deserialize, TS, Clone, Debug, PartialEq)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub struct EqSettings {
    pub enabled: bool,
    /// Gain in dB for each of the 10 bands (31 Hz … 16 kHz), each within ±12.
    pub bands: Vec<f32>,
    /// Preamp in dB (±12). Automatic headroom is applied on top of it.
    pub preamp: f32,
    /// The preset these values came from, or `None` after a manual change.
    pub preset: Option<String>,
}

impl Default for EqSettings {
    fn default() -> Self { EqSettings { enabled: false, bands: vec![0.0; 10], preamp: 0.0, preset: Some("Flat".into()) } }
}

#[derive(Serialize, Deserialize, TS, Clone, Debug, PartialEq, Default)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub struct DspState { pub eq: EqSettings, pub crossfade_secs: f32, pub replay_gain: ReplayGainMode }

#[derive(Serialize, Deserialize, TS, Clone, Debug, PartialEq)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub struct EqPreset { pub name: String, pub bands: Vec<f32>, pub preamp: f32, pub builtin: bool }

#[derive(Serialize, Deserialize, TS, Clone, Debug)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub struct SetEqParams {
    pub bands: Vec<f32>,
    pub preamp: f32,
    #[serde(default)] #[ts(optional)] pub preset: Option<String>,
}

#[derive(Serialize, Deserialize, TS, Clone, Debug)]
#[serde(rename_all = "camelCase")]
#[ts(export)]
pub struct EnabledParams { pub enabled: bool }

#[derive(Serialize, Deserialize, TS, Clone, Debug)]

#[ts(export)]

#[derive(Serialize, Deserialize, TS, Clone, Debug)]
```

```rust
//! 10-band graphic EQ (spec §3.6): RBJ peaking biquads at fixed ISO-ish centres, a preamp and
//! automatic headroom. Runs in the output callback, so processing never allocates.
use std::sync::atomic::{fence, AtomicBool, AtomicU32, AtomicU64, Ordering::*};

use protocol::EqPreset;

use crate::output::format::DeviceSample;

pub const BANDS_HZ: [f64; 10] = [31.0, 62.0, 125.0, 250.0, 500.0, 1000.0, 2000.0, 4000.0, 8000.0, 16000.0];
pub const BAND_Q: f64 = 1.41;
pub const MAX_DB: f32 = 12.0;
const MAX_CHANNELS: usize = 8;

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Biquad { pub b0: f64, pub b1: f64, pub b2: f64, pub a1: f64, pub a2: f64 }

impl Biquad {
    pub const IDENTITY: Biquad = Biquad { b0: 1.0, b1: 0.0, b2: 0.0, a1: 0.0, a2: 0.0 };
}

/// RBJ "Audio EQ Cookbook" peaking filter, normalised by a0.
pub fn peaking(fs: f64, f0: f64, q: f64, gain_db: f64) -> Biquad {
    if gain_db == 0.0 || f0 >= 0.45 * fs { return Biquad::IDENTITY; }
    let a = 10f64.powf(gain_db / 40.0);
    let w0 = 2.0 * std::f64::consts::PI * f0 / fs;
    let (sin, cos) = w0.sin_cos();
    let alpha = sin / (2.0 * q);
    let a0 = 1.0 + alpha / a;
    Biquad { b0: (1.0 + alpha * a) / a0, b1: -2.0 * cos / a0, b2: (1.0 - alpha * a) / a0, a1: -2.0 * cos / a0, a2: (1.0 - alpha / a) / a0 }
}

/// |H(e^jw)| in dB at `f`.
pub fn magnitude_db(b: &Biquad, f: f64, fs: f64) -> f64 {
    let w = 2.0 * std::f64::consts::PI * f / fs;
    let (c1, s1, c2, s2) = (w.cos(), w.sin(), (2.0 * w).cos(), (2.0 * w).sin());
    let (nr, ni) = (b.b0 + b.b1 * c1 + b.b2 * c2, -(b.b1 * s1 + b.b2 * s2));
    let (dr, di) = (1.0 + b.a1 * c1 + b.a2 * c2, -(b.a1 * s1 + b.a2 * s2));
    10.0 * ((nr * nr + ni * ni) / (dr * dr + di * di)).log10()
}

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct EqDesign { pub stages: [Biquad; 10], pub active: [bool; 10], pub gain: f64 }

impl EqDesign {
    pub fn new(fs: u32, bands_db: &[f32; 10], preamp_db: f32) -> Self {
        let mut stages = [Biquad::IDENTITY; 10];
        let mut active = [false; 10];
        for (i, (&f0, &g)) in BANDS_HZ.iter().zip(bands_db).enumerate() {
            stages[i] = peaking(fs as f64, f0, BAND_Q, g.clamp(-MAX_DB, MAX_DB) as f64);
            active[i] = stages[i] != Biquad::IDENTITY;
        }
        // Automatic headroom: a boost can push a full-scale signal past 0 dBFS, so the preamp drops by the largest boost.
        let headroom = bands_db.iter().fold(0f32, |m, b| m.max(b.clamp(-MAX_DB, MAX_DB)));
        let gain_db = preamp_db.clamp(-MAX_DB, MAX_DB) - headroom;
        EqDesign { stages, active, gain: if gain_db == 0.0 { 1.0 } else { 10f64.powf(gain_db as f64 / 20.0) } }
    }

    pub fn is_identity(&self) -> bool { !self.active.iter().any(|a| *a) && self.gain == 1.0 }
}

/// Filter memory (transposed direct form II) for up to 8 interleaved channels.
pub struct EqState { channels: usize, z: [[[f64; 2]; 10]; MAX_CHANNELS] }

impl EqState {
    pub fn new(channels: usize) -> Self { EqState { channels: channels.clamp(1, MAX_CHANNELS), z: [[[0.0; 2]; 10]; MAX_CHANNELS] } }

    fn run(&mut self, d: &EqDesign, ch: usize, x: f64) -> f64 {
        let mut y = x * d.gain;
        for (i, b) in d.stages.iter().enumerate() {
            if !d.active[i] { continue; }
            let z = &mut self.z[ch][i];
            let out = b.b0 * y + z[0];
            z[0] = b.b1 * y - b.a1 * out + z[1];
            z[1] = b.b2 * y - b.a2 * out;
            y = out;
        }
        y
    }

    /// Filters interleaved device-format samples in place. Realtime-safe.
    pub fn process(&mut self, d: &EqDesign, buf: &mut [u8], sample: DeviceSample) {
        if d.is_identity() { return; }
        let ch = self.channels;
        match sample {
            DeviceSample::F32 => for (i, c) in buf.as_chunks_mut::<4>().0.iter_mut().enumerate() {
                *c = (self.run(d, i % ch, f32::from_le_bytes(*c) as f64) as f32).to_le_bytes();
            },
            DeviceSample::I16 => for (i, c) in buf.as_chunks_mut::<2>().0.iter_mut().enumerate() {
                let y = self.run(d, i % ch, i16::from_le_bytes(*c) as f64);
                *c = (y.round().clamp(i16::MIN as f64, i16::MAX as f64) as i16).to_le_bytes();
            },
            DeviceSample::I24 => for (i, c) in buf.as_chunks_mut::<3>().0.iter_mut().enumerate() {
                let x = i32::from_le_bytes([0, c[0], c[1], c[2]]) >> 8;
                let y = self.run(d, i % ch, x as f64).round().clamp(-8_388_608.0, 8_388_607.0) as i32;
                c.copy_from_slice(&y.to_le_bytes()[..3]);
            },
            DeviceSample::I32 => for (i, c) in buf.as_chunks_mut::<4>().0.iter_mut().enumerate() {
                let y = self.run(d, i % ch, i32::from_le_bytes(*c) as f64);
                *c = (y.round().clamp(i32::MIN as f64, i32::MAX as f64) as i32).to_le_bytes();
            },
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct EqSnapshot { pub seq: u64, pub enabled: bool, pub bands: [f32; 10], pub preamp: f32 }

/// EQ settings shared from the player thread (the only writer) to output callbacks, as a seqlock:
/// a reader never blocks, and a read that overlaps a write is discarded.
pub struct EqShared { seq: AtomicU64, enabled: AtomicBool, values: [AtomicU32; 11] }

impl Default for EqShared { fn default() -> Self { Self::new() } }

impl EqShared {
    pub fn new() -> Self { EqShared { seq: AtomicU64::new(0), enabled: AtomicBool::new(false), values: std::array::from_fn(|_| AtomicU32::new(0)) } }

    pub fn seq(&self) -> u64 { self.seq.load(Acquire) }

    pub fn publish(&self, enabled: bool, bands: &[f32], preamp: f32) {
        let s = self.seq.load(Relaxed);
        self.seq.store(s + 1, Relaxed);
        fence(Release);
        self.enabled.store(enabled, Relaxed);
        for (i, v) in self.values.iter().enumerate().take(10) { v.store(bands.get(i).copied().unwrap_or(0.0).to_bits(), Relaxed); }
        self.values[10].store(preamp.to_bits(), Relaxed);
        self.seq.store(s + 2, Release);
    }

    pub fn read(&self) -> Option<EqSnapshot> {
        let s1 = self.seq.load(Acquire);
        if s1 & 1 == 1 { return None; }
        let enabled = self.enabled.load(Relaxed);
        let bands = std::array::from_fn(|i| f32::from_bits(self.values[i].load(Relaxed)));
        let preamp = f32::from_bits(self.values[10].load(Relaxed));
        fence(Acquire);
        (self.seq.load(Relaxed) == s1).then_some(EqSnapshot { seq: s1, enabled, bands, preamp })
    }
}
```

```rust
//! ReplayGain (spec §3.6): track/album/off from tag values, with peak protection.
use protocol::{ReplayGainInfo, ReplayGainMode};

/// Highest allowed peak after gain, in dBFS.
pub const PEAK_CEILING_DB: f64 = -0.1;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum RgSource { Track, Album }

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct RgDecision {
    /// Gain to apply in dB (0 when off or without data).
    pub db: f64,
    /// Which tag values were used; `None` when off or the track has none.
    pub source: Option<RgSource>,
    /// The gain was lowered so the peak stays under `PEAK_CEILING_DB`.
    pub limited: bool,
}

impl RgDecision {
    pub const NONE: RgDecision = RgDecision { db: 0.0, source: None, limited: false };
    pub fn linear(&self) -> f64 { if self.db == 0.0 { 1.0 } else { 10f64.powf(self.db / 20.0) } }
}

pub fn decide(mode: ReplayGainMode, info: &ReplayGainInfo) -> RgDecision {
    let track = info.track_gain.map(|g| (g, info.track_peak, RgSource::Track));
    let album = info.album_gain.map(|g| (g, info.album_peak, RgSource::Album));
    let chosen = match mode {
        ReplayGainMode::Off => None,
        ReplayGainMode::Track => track.or(album),
        ReplayGainMode::Album => album.or(track),
    };
    let Some((gain, peak, source)) = chosen else { return RgDecision::NONE };
    // A missing peak counts as full scale: no boost then, only cuts.
    let peak = peak.filter(|p| *p > 0.0).unwrap_or(1.0) as f64;
    let max_db = PEAK_CEILING_DB - 20.0 * peak.log10();
    let gain = gain as f64;
    if gain > max_db { RgDecision { db: max_db, source: Some(source), limited: true } } else { RgDecision { db: gain, source: Some(source), limited: false } }
}
```

  - **`Player::dsp_stages`** returns `[rg, eq, crossfade]`.

**How the crossfade works** (for the implementer; these are the rules the tests pin):
1. **Trigger:** while decoding the outgoing track A in processed mode with crossfade > 0, before each block the player checks every condition below. When all hold, it enters a `Crossfade` state:
   - the next track B (by `auto_next`) is already pre-opened in `self.prepared`;
   - B isn't A itself (repeat-one replays aren't crossfaded, R2);
   - A and B aren't `same_album_in_order` (smart skip);
   - both durations are known;
   - A's remaining time is ≤ `overlap + XFADE_LEAD_SECS` (1 s);
   - B's plan keeps the open stream's format.
   If B's plan would change format, the player remembers that it declined for A (`xfade_declined`) and doesn't re-plan on every block.
2. **Tail:** the rest of A is decoded into an f64 `tail` until A's end (chain flushed), so its exact remaining length `R` is known. Then `total = min(round(overlap · out_rate), R)`.
3. **Unmixed part:** the first `R − total` frames of the tail are encoded as A's audio.
4. **Mixed part:** B's marker is pushed at the current ring position (B becomes "now playing" there). The last `total` frames of A are then mixed with B's first `total` rendered frames using `equal_power(i / total)`, and encoded with B's chain.
5. **Hand-over:** when `total` frames are mixed, B's unmixed rendered remainder is encoded, `feeding = B`, and normal playback continues.

The output length is therefore always `len(A) + len(B) − total`.

```rust
//! Crossfade maths (spec §3.6): equal-power curve, overlap length, and smart skip.

/// (outgoing gain, incoming gain) at position `t` in 0..=1 of the overlap; their squares sum to 1.
pub fn equal_power(t: f64) -> (f64, f64) {
    let a = t.clamp(0.0, 1.0) * std::f64::consts::FRAC_PI_2;
    (a.cos(), a.sin())
}

/// The overlap in seconds: the setting, shrunk to half of the shorter track.
pub fn overlap_secs(fade: f64, a_secs: f64, b_secs: f64) -> f64 { fade.min(a_secs / 2.0).min(b_secs / 2.0).max(0.0) }

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct AlbumPos { pub album_id: Option<i64>, pub disc: Option<u32>, pub track: Option<u32> }

/// True when `b` directly follows `a` on the same album, so the pair must stay gapless.
pub fn same_album_in_order(a: AlbumPos, b: AlbumPos) -> bool {
    let (Some(album), Some(at), Some(bt)) = (a.album_id, a.track, b.track) else { return false };
    if b.album_id != Some(album) { return false; }
    let (ad, bd) = (a.disc.unwrap_or(1), b.disc.unwrap_or(1));
    (bd == ad && bt == at + 1) || (bd == ad + 1 && bt == 1)
}
```

```rust
    /// Processed samples for `block` at the output rate (channel-mapped, resampled, gained), appended to `out`.
    pub fn render(&mut self, block: &PcmBlock, out: &mut Vec<f64>) {
        self.f.clear();
        block.to_f64(&mut self.f);
        self.mapped.clear();
        self.plan.channel_map.apply(&self.f, &mut self.mapped);
        let start = out.len();
        match self.resampler.as_mut() {
            Some(r) => r.process(&self.mapped, out),
            None => out.extend_from_slice(&self.mapped),
        }
        if self.gain != 1.0 { for s in &mut out[start..] { *s *= self.gain; } }
    }

    /// The resampler's buffered tail (with gain), appended to `out`.
    pub fn render_flush(&mut self, out: &mut Vec<f64>) {
        let start = out.len();
        if let Some(r) = self.resampler.as_mut() { r.flush(out); }
        if self.gain != 1.0 { for s in &mut out[start..] { *s *= self.gain; } }
    }

    /// Device bytes for processed samples, with this chain's dither.
    pub fn encode(&mut self, samples: &[f64], out: &mut Vec<u8>) {
        let dither = self.plan.dither.then_some(&mut self.dither);
        write_f64(samples, self.plan.format.sample, dither, out);
    }

    pub fn process(&mut self, block: &PcmBlock, out: &mut Vec<u8>) {
        debug_assert_eq!(block.spec.channels, self.src.channels);
        match (self.plan.passthrough, &block.data) {
            (Passthrough::Int | Passthrough::Dop, PcmData::Int(v)) => return write_int_passthrough(v, self.plan.format.sample, out),
            (Passthrough::Float, PcmData::Float(v)) => return write_f32_passthrough(v, out),
            _ => {}
        }
        let mut r = std::mem::take(&mut self.rendered);
        r.clear();
        self.render(block, &mut r);
        self.encode(&r, out);
        self.rendered = r;
    }

    pub fn flush(&mut self, out: &mut Vec<u8>) {
        let mut r = std::mem::take(&mut self.rendered);
        r.clear();
        self.render_flush(&mut r);
        if !r.is_empty() { self.encode(&r, out); }
        self.rendered = r;
    }
```

```rust
    fn maybe_start_crossfade(&mut self) -> bool {
        if self.crossfade_secs <= 0.0 || !self.dsp_allowed() { return false; }
        let Some(feed) = &self.feeding else { return false };
        if feed.chain.plan().passthrough != Passthrough::None || self.xfade_declined == Some(feed.idx) { return false; }

    /// One unit of crossfade work: decode a block of the outgoing tail, write unmixed tail frames,
    /// or mix and write a slice of the overlap. Finishes by handing feeding over to the incoming track.
    fn crossfade_step(&mut self) {
        const SLICE: usize = 4096;
        let ch = self.active.as_ref().map_or(2, |a| a.info.format.channels as usize);
        let mut x = self.xfade.take().expect("crossfade_step with xfade");
        let Some(feed) = self.feeding.as_mut() else { return };
        if !x.tail_done {
            match feed.dec.next_block() {
                Ok(Some(block)) => { feed.decoded += block.frames() as u64; feed.chain.render(&block, &mut x.tail); }
                Ok(None) => { feed.chain.render_flush(&mut x.tail); x.tail_done = true; }
                Err(e) => { let idx = feed.idx; feed.chain.render_flush(&mut x.tail); x.tail_done = true; self.track_error(idx, &e); }
            }
            if x.tail_done { x.total = x.planned.min(x.tail.len() / ch); }
            self.xfade = Some(x);
            return;
        }
        let tail_frames = x.tail.len() / ch;
        let unmixed_end = tail_frames - x.total;
        let mut bytes = Vec::new();
        if x.pos < unmixed_end {
            let n = (unmixed_end - x.pos).min(SLICE);
            feed.chain.encode(&x.tail[x.pos * ch..(x.pos + n) * ch], &mut bytes);
            x.pos += n;
            self.push_bytes(bytes);
            self.xfade = Some(x);
            return;
        }
        if !x.marker_pushed {
            let info = x.inc.dec.info().clone();
            let plan = x.inc.chain.plan().clone();
            self.push_marker(x.inc.idx, &info, &plan, 0);
            x.marker_pushed = true;
        }
        if x.mixed < x.total {
            let n = (x.total - x.mixed).min(SLICE);
            while x.head.len() / ch < n && !x.inc.eof {
                match x.inc.dec.next_block() {
                    Ok(Some(block)) => { x.inc.decoded += block.frames() as u64; x.inc.chain.render(&block, &mut x.head); }
                    Ok(None) => { x.inc.chain.render_flush(&mut x.head); x.inc.eof = true; }
                    Err(e) => { let idx = x.inc.idx; x.inc.eof = true; self.track_error(idx, &e); }
                }
            }
            let mut mixed = Vec::with_capacity(n * ch);
            for f in 0..n {
                let (go, gi) = equal_power((x.mixed + f) as f64 / x.total as f64);
                for c in 0..ch {
                    let a = x.tail.get((x.pos + f) * ch + c).copied().unwrap_or(0.0);
                    let b = x.head.get(f * ch + c).copied().unwrap_or(0.0);
                    mixed.push(a * go + b * gi);
                }
            }
            x.head.drain(..(n * ch).min(x.head.len()));
            x.inc.chain.encode(&mixed, &mut bytes);
            x.mixed += n;
            x.pos += n;
            self.push_bytes(bytes);
            self.xfade = Some(x);
            return;
        }
        // Overlap done: the incoming track's already-rendered rest is written, then it feeds normally.
        if !x.head.is_empty() { x.inc.chain.encode(&x.head, &mut bytes); self.push_bytes(bytes); }
        self.feeding = Some(x.inc);
        self.prepared = None;
        self.prepare_failed = None;
        self.xfade_declined = None;
    }
```

```rust
struct DspFile { version: u32, state: DspState, presets: Vec<EqPreset> }

fn valid_db(v: f32) -> bool { v.is_finite() && v.abs() <= MAX_DB }

    pub fn load(dir: Option<&Path>) -> Self {

            Some(f) => DspStore { state: f.state, user: f.presets.into_iter().filter(|p| !p.builtin).collect(), path },
            None => DspStore { state: DspState::default(), user: vec![], path },
        }
    }

    pub fn state(&self) -> &DspState { &self.state }

    pub fn presets(&self) -> Vec<EqPreset> {
        let mut user = self.user.clone();
        user.sort_by_key(|p| p.name.to_lowercase());
        builtin_presets().into_iter().chain(user).collect()
    }

    pub fn commands(&self) -> Vec<Command> {
        vec![Command::SetEq(self.state.eq.clone()), Command::SetCrossfade(self.state.crossfade_secs), Command::SetReplayGain(self.state.replay_gain)]
    }

    fn find(&self, name: &str) -> Option<EqPreset> { self.presets().into_iter().find(|p| p.name == name) }

    pub fn set_eq(&mut self, p: SetEqParams) -> Result<(), String> {
        if p.bands.len() != 10 { return Err("bands must have exactly 10 values".into()); }
        if !p.bands.iter().all(|b| valid_db(*b)) || !valid_db(p.preamp) { return Err(format!("gains must be within ±{MAX_DB} dB")); }
        if let Some(name) = &p.preset && self.find(name).is_none() { return Err(format!("no preset named {name:?}")); }
        self.state.eq.bands = p.bands;
        self.state.eq.preamp = p.preamp;
        self.state.eq.preset = p.preset;
        self.save();
        Ok(())
    }

    pub fn set_eq_enabled(&mut self, on: bool) -> Result<(), String> { self.state.eq.enabled = on; self.save(); Ok(()) }

    pub fn save_preset(&mut self, name: &str) -> Result<EqPreset, String> {
        let name = name.trim();
        if name.is_empty() || name.chars().count() > MAX_PRESET_NAME { return Err(format!("preset names are 1–{MAX_PRESET_NAME} characters")); }
        if builtin_presets().iter().any(|p| p.name.eq_ignore_ascii_case(name)) { return Err(format!("{name:?} is a built-in preset")); }
        let preset = EqPreset { name: name.into(), bands: self.state.eq.bands.clone(), preamp: self.state.eq.preamp, builtin: false };
        self.user.retain(|p| p.name != name);
        self.user.push(preset.clone());
        self.state.eq.preset = Some(name.into());
        self.save();
        Ok(preset)
    }

    pub fn delete_preset(&mut self, name: &str) -> Result<(), String> {
        if builtin_presets().iter().any(|p| p.name == name) { return Err(format!("{name:?} is a built-in preset")); }
        let before = self.user.len();
        self.user.retain(|p| p.name != name);
        if self.user.len() == before { return Err(format!("no preset named {name:?}")); }
        if self.state.eq.preset.as_deref() == Some(name) { self.state.eq.preset = None; }
        self.save();
        Ok(())
    }

    pub fn set_crossfade(&mut self, secs: f32) -> Result<(), String> {
        if !secs.is_finite() || !(0.0..=MAX_CROSSFADE_SECS).contains(&secs) { return Err(format!("crossfade must be 0–{MAX_CROSSFADE_SECS} s")); }
        self.state.crossfade_secs = secs;
        self.save();
        Ok(())
    }

    pub fn set_replay_gain(&mut self, mode: ReplayGainMode) -> Result<(), String> { self.state.replay_gain = mode; self.save(); Ok(()) }

    fn save(&self) {
        let Some(path) = &self.path else { return };
        let file = DspFile { version: VERSION, state: self.state.clone(), presets: self.user.clone() };
        let tmp = path.with_extension("json.tmp");
        let res = serde_json::to_vec_pretty(&file).map_err(std::io::Error::other).and_then(|b| std::fs::write(&tmp, b)).and_then(|_| std::fs::rename(&tmp, path));
        if let Err(e) = res { tracing::warn!(error = %e, "couldn't save dsp.json"); }
    }
}
```

```rust
/// Applies a DSP change. On success:
/// - the player gets the settings that changed, and only those: a ReplayGain change resyncs the
///   audible track, so it mustn't be resent for an EQ change;
/// - every window gets `dsp.changed`;
/// - the caller gets the new state.
fn dsp_change(ctx: &Ctx, change: impl FnOnce(&mut super::dsp::DspStore) -> Result<(), String>) -> Result<Outcome, RpcError> {
    let mut d = ctx.dsp.lock().unwrap();
    let before = d.state().clone();
    change(&mut d).map_err(|m| err(ErrorCode::InvalidArgument.code(), m))?;
    let after = d.state();
    if after.eq != before.eq { ctx.player.send(Command::SetEq(after.eq.clone())); }
    if after.crossfade_secs != before.crossfade_secs { ctx.player.send(Command::SetCrossfade(after.crossfade_secs)); }
    if after.replay_gain != before.replay_gain { ctx.player.send(Command::SetReplayGain(after.replay_gain)); }
    ctx.out.notify("dsp.changed", after);
    Ok(Outcome::Reply(serde_json::to_value(after).unwrap()))
}
```

**LRC rules** (pinned by the unit tests):
- **Time tags:** `[mm:ss]`, `[mm:ss.x]`, `[mm:ss.xx]` or `[mm:ss.xxx]`, with `:` also accepted as the fraction separator. Minutes may be more than 2 digits.
- **Repeated tags:** several leading time tags on one line produce one line each.
- **`[offset:±N]`:** N milliseconds; a positive offset makes lyrics appear earlier, so t = max(0, t − N).
- **Metadata tags:** any other `[key:value]` is skipped, and so are untimed lines.
- **Enhanced LRC:** `<mm:ss.xx>` tags inside the text make `words`; `text` is the line without the tags.
- **Order:** lines are sorted by time, stably.

```rust
//! Lyrics (spec §3.9): sidecar `.lrc`, embedded text tags and ID3 SYLT; synced or plain.
use std::path::Path;

use lofty::prelude::*;
use lofty::tag::ItemKey;
use protocol::{Lyrics, LyricLine, LyricWord};

/// UTF-8 (BOM stripped), or Latin-1 when the bytes aren't UTF-8 (common in older `.lrc` files).
pub fn decode_text(bytes: &[u8]) -> String {
    let bytes = bytes.strip_prefix(b"\xEF\xBB\xBF").unwrap_or(bytes);
    match std::str::from_utf8(bytes) {
        Ok(s) => s.to_string(),
        Err(_) => bytes.iter().map(|&b| b as char).collect(),
    }
}

/// `mm:ss`, `mm:ss.f+` or `mm:ss:f+` → milliseconds.
fn parse_time(s: &str) -> Option<u32> {
    let (min, rest) = s.split_once(':')?;
    let (sec, frac) = match rest.find(['.', ':']) { Some(i) => (&rest[..i], Some(&rest[i + 1..])), None => (rest, None) };
    if min.is_empty() || !min.bytes().all(|b| b.is_ascii_digit()) || sec.len() != 2 || !sec.bytes().all(|b| b.is_ascii_digit()) { return None; }
    let (min, sec): (u32, u32) = (min.parse().ok()?, sec.parse().ok()?);
    if sec >= 60 { return None; }
    let ms = match frac {
        None => 0,
        Some(f) if !f.is_empty() && f.len() <= 3 && f.bytes().all(|b| b.is_ascii_digit()) => f.parse::<u32>().ok()? * 10u32.pow(3 - f.len() as u32),
        Some(_) => return None,
    };
    Some(min * 60_000 + sec * 1000 + ms)
}

/// Splits enhanced-LRC `<mm:ss.xx>` word tags out of a line's text. Text before the first tag is
/// kept only in the line text; each word runs from its tag to the next one.
fn words(text: &str) -> (String, Option<Vec<LyricWord>>) {
    let mut out: Vec<LyricWord> = Vec::new();
    let mut lead = String::new();
    let mut rest = text;
    while let Some(open) = rest.find('<') {
        let Some(close) = rest[open..].find('>').map(|c| open + c) else { break };
        let Some(t) = parse_time(&rest[open + 1..close]) else { break };
        match out.last_mut() { Some(w) => w.text.push_str(&rest[..open]), None => lead.push_str(&rest[..open]) }
        out.push(LyricWord { t_ms: t, text: String::new() });
        rest = &rest[close + 1..];
    }
    match out.last_mut() { Some(w) => w.text.push_str(rest), None => return (text.trim().to_string(), None) }
    let joined: String = std::iter::once(lead.as_str()).chain(out.iter().map(|w| w.text.as_str())).collect();
    (joined.trim().to_string(), Some(out))
}

pub fn parse_lrc(text: &str) -> Option<Lyrics> {
    let text = text.strip_prefix('\u{feff}').unwrap_or(text);
    let mut offset: i64 = 0;
    let mut lines: Vec<LyricLine> = Vec::new();
    for raw in text.lines() {
        let mut rest = raw.trim_end_matches('\r').trim_start();
        let mut stamps = Vec::new();
        while let Some(tag) = rest.strip_prefix('[').and_then(|r| r.find(']').map(|c| (&r[..c], &r[c + 1..]))) {
            let (inner, after) = tag;
            if let Some(t) = parse_time(inner) {
                stamps.push(t);
            } else if let Some(v) = inner.strip_prefix("offset:") {
                offset = v.trim().parse().unwrap_or(0);
            } else if stamps.is_empty() {
                // A metadata tag ([ar:], [ti:] …) or a malformed one: the line isn't lyrics.
                rest = "";
                break;
            } else {
                break;
            }
            rest = after;
        }
        if stamps.is_empty() { continue; }
        let (line_text, line_words) = words(rest);
        for t in stamps {
            let shift = |t: u32| (t as i64 - offset).max(0) as u32;
            lines.push(LyricLine {
                t_ms: Some(shift(t)),
                text: line_text.clone(),
                words: line_words.as_ref().map(|ws| ws.iter().map(|w| LyricWord { t_ms: shift(w.t_ms), text: w.text.clone() }).collect()),
            });
        }
    }
    if lines.is_empty() { return None; }
    lines.sort_by_key(|l| l.t_ms);
    Some(Lyrics { synced: true, lines })
}

pub fn plain(text: &str) -> Lyrics {
    let text = text.strip_prefix('\u{feff}').unwrap_or(text);
    let all: Vec<&str> = text.lines().map(|l| l.trim_end_matches('\r').trim_end()).collect();
    let start = all.iter().position(|l| !l.is_empty()).unwrap_or(all.len());
    let end = all.iter().rposition(|l| !l.is_empty()).map_or(start, |e| e + 1);
    Lyrics { synced: false, lines: all[start..end].iter().map(|l| LyricLine { t_ms: None, text: (*l).to_string(), words: None }).collect() }
}

fn sidecar(path: &Path) -> Option<String> {
    ["lrc", "LRC"].iter().find_map(|ext| std::fs::read(path.with_extension(ext)).ok()).map(|b| decode_text(&b))
}

fn embedded_text(path: &Path) -> Option<String> {
    let tf = lofty::read_from_path(path).ok()?;
    let tag = tf.primary_tag().or_else(|| tf.first_tag())?;
    [ItemKey::Lyrics, ItemKey::UnsyncLyrics].into_iter().find_map(|k| tag.get_string(k).map(str::to_string)).filter(|s| !s.trim().is_empty())
}

/// ID3v2 SYLT with millisecond timestamps (MPEG-frame timestamps are skipped).
fn sylt(path: &Path) -> Option<Lyrics> {
    use lofty::config::ParseOptions;
    use lofty::file::AudioFile;
    use lofty::id3::v2::{Frame, SynchronizedTextFrame, TimestampFormat};
    use lofty::mpeg::MpegFile;
    if crate::tags::container_of(path) != "mp3" { return None; }
    let mp3 = MpegFile::read_from(&mut std::fs::File::open(path).ok()?, ParseOptions::new()).ok()?;

        let Ok(s) = SynchronizedTextFrame::parse(&bin.data, frame.flags()) else { continue };

        if lines.is_empty() { continue; }
        lines.sort_by_key(|l| l.t_ms);
        return Some(Lyrics { synced: true, lines });
    }
    None
}

/// The first synced source (sidecar → SYLT → embedded text), else the first plain one.
pub fn for_file(path: &Path) -> Option<Lyrics> {
    let mut fallback: Option<Lyrics> = None;
    if let Some(t) = sidecar(path) {
        match parse_lrc(&t) { Some(l) => return Some(l), None => { fallback.get_or_insert_with(|| plain(&t)); } }
    }
    if let Some(l) = sylt(path) { return Some(l); }
    if let Some(t) = embedded_text(path) {
        match parse_lrc(&t) { Some(l) => return Some(l), None => { fallback.get_or_insert_with(|| plain(&t)); } }
    }
    fallback.filter(|l| !l.lines.is_empty())
}
```

```rust
//! Spectrum analyzer (spec §3.6): 2048-point FFT, Hann window, 64 log-spaced bands, 30 fps.
use std::sync::Arc;

use realfft::num_complex::Complex;
use realfft::{RealFftPlanner, RealToComplex};

pub const FFT_SIZE: usize = 2048;
pub const BINS: usize = 64;
pub const FPS: u32 = 30;
const MIN_HZ: f64 = 30.0;
const MAX_HZ: f64 = 16_000.0;
const FLOOR_DB: f32 = -80.0;

pub struct Analyzer {
    fft: Arc<dyn RealToComplex<f32>>,
    window: Vec<f32>,
    input: Vec<f32>,
    spectrum: Vec<Complex<f32>>,
    scratch: Vec<Complex<f32>>,
    /// FFT bin range (inclusive) of each band.
    ranges: [(usize, usize); BINS],
    /// Divides |X[k]| so a full-scale sine reads 1.0 (0 dBFS).
    norm: f32,
    rate: u32,
}

impl Analyzer {
    pub fn new(rate: u32) -> Self {
        let fft = RealFftPlanner::<f32>::new().plan_fft_forward(FFT_SIZE);
        let window: Vec<f32> = (0..FFT_SIZE).map(|n| (0.5 - 0.5 * (2.0 * std::f64::consts::PI * n as f64 / (FFT_SIZE - 1) as f64).cos()) as f32).collect();
        let norm = window.iter().sum::<f32>() / 2.0;
        let hi = MAX_HZ.min(rate as f64 / 2.0);
        let half = FFT_SIZE / 2;
        let bin = |hz: f64| ((hz * FFT_SIZE as f64 / rate as f64).round() as usize).clamp(1, half);
        let edge = |i: usize| MIN_HZ * (hi / MIN_HZ).powf(i as f64 / BINS as f64);
        let ranges = std::array::from_fn(|i| { let lo = bin(edge(i)); (lo, bin(edge(i + 1)).max(lo)) });
        Analyzer { input: fft.make_input_vec(), spectrum: fft.make_output_vec(), scratch: fft.make_scratch_vec(), fft, window, ranges, norm, rate }
    }

    /// The band a frequency falls in (clamped to the first/last band).
    pub fn band_of(&self, hz: f64) -> usize {
        let hi = MAX_HZ.min(self.rate as f64 / 2.0);
        let pos = (hz.max(MIN_HZ) / MIN_HZ).ln() / (hi / MIN_HZ).ln() * BINS as f64;
        (pos.floor() as usize).min(BINS - 1)
    }

    pub fn analyze(&mut self, mono: &[f32]) -> [u8; BINS] {
        debug_assert_eq!(mono.len(), FFT_SIZE);
        for ((d, s), w) in self.input.iter_mut().zip(mono).zip(&self.window) { *d = s * w; }
        if self.fft.process_with_scratch(&mut self.input, &mut self.spectrum, &mut self.scratch).is_err() { return [0; BINS]; }
        std::array::from_fn(|i| {
            let (lo, hi) = self.ranges[i];
            let peak = self.spectrum[lo..=hi].iter().map(|c| c.norm()).fold(0f32, f32::max) / self.norm;
            if peak <= 0.0 { return 0; }
            let db = 20.0 * peak.log10();
            ((db - FLOOR_DB) / -FLOOR_DB * 255.0).round().clamp(0.0, 255.0) as u8
        })
    }
}
```

```rust
    fn tap_step(&mut self, buf: &[u8]) {
        let Some(tap) = self.tap.as_mut() else { return };
        let (bpf, ch) = (self.bpf, self.channels);
        let bytes = self.sample.bytes();

            let mut sum = 0f32;

                    DeviceSample::I32 => i32::from_le_bytes([c[0], c[1], c[2], c[3]]) as f32 / 2_147_483_648.0,
```

```rust
//! Spectrum analyzer thread: reads the current stream's tap and sends `PlayerEvent::Spectrum` at 30 fps.
use std::collections::VecDeque;
use std::time::{Duration, Instant};

use crossbeam_channel::{Receiver, RecvTimeoutError, Sender};

use super::PlayerEvent;
use crate::dsp::spectrum::{Analyzer, FFT_SIZE, FPS};

pub struct TapStream { pub tap: rtrb::Consumer<f32>, pub rate: u32 }

/// Runs until `rx` disconnects (the player shut down). Each new stream replaces the previous tap.
pub fn spawn(events: Sender<PlayerEvent>) -> Sender<TapStream> {
    let (tx, rx) = crossbeam_channel::unbounded::<TapStream>();
    std::thread::Builder::new().name("aurora-viz".into()).spawn(move || run(rx, events)).expect("spawn viz thread");
    tx
}

fn run(rx: Receiver<TapStream>, events: Sender<PlayerEvent>) {
    let period = Duration::from_secs(1) / FPS;
    let mut current: Option<(TapStream, Analyzer)> = None;
    let mut window: VecDeque<f32> = VecDeque::with_capacity(FFT_SIZE);
    let mut buf = vec![0f32; FFT_SIZE];
    let mut fresh = false;
    let mut next = Instant::now();
    loop {
        match rx.recv_timeout(next.saturating_duration_since(Instant::now())) {
            Ok(s) => { let a = Analyzer::new(s.rate); current = Some((s, a)); window.clear(); continue; }
            Err(RecvTimeoutError::Disconnected) => return,
            Err(RecvTimeoutError::Timeout) => {}
        }
        next += period;
        if next < Instant::now() { next = Instant::now() + period; }
        let Some((stream, analyzer)) = current.as_mut() else { continue };
        while let Ok(v) = stream.tap.pop() {
            if window.len() == FFT_SIZE { window.pop_front(); }
            window.push_back(v);
            fresh = true;
        }
        // Frames only while new audio arrives: paused or viz off means no frames.
        if !fresh || window.len() < FFT_SIZE { continue; }
        fresh = false;
        for (d, s) in buf.iter_mut().zip(&window) { *d = *s; }
        let _ = events.send(PlayerEvent::Spectrum(analyzer.analyze(&buf)));
    }
}
```

```ts
/** The engine's stdout (spec §4.1): newline-delimited JSON lines interleaved with binary frames
 * (0x1E, u32 LE length, payload = [type, ...data]). JSON lines never start with 0x1E. */
export type Chunk = { kind: 'line'; text: string } | { kind: 'frame'; type: number; data: Uint8Array }

const MARK = 0x1e
const NL = 0x0a

export class StreamDecoder {
  private buf = new Uint8Array(0)
  private text = new TextDecoder('utf-8')

  push(chunk: Uint8Array): Chunk[] {
    const next = new Uint8Array(this.buf.length + chunk.length)
    next.set(this.buf)
    next.set(chunk, this.buf.length)
    this.buf = next
    const out: Chunk[] = []
    let pos = 0
    for (;;) {
      if (pos >= this.buf.length) break
      if (this.buf[pos] === MARK) {
        if (this.buf.length - pos < 5) break
        const len = new DataView(this.buf.buffer, this.buf.byteOffset + pos + 1, 4).getUint32(0, true)
        if (this.buf.length - pos < 5 + len) break
        const payload = this.buf.slice(pos + 5, pos + 5 + len)
        if (len > 0) out.push({ kind: 'frame', type: payload[0], data: payload.slice(1) })
        pos += 5 + len
        continue
      }
      const nl = this.buf.indexOf(NL, pos)
      if (nl < 0) break
      const line = this.text.decode(this.buf.subarray(pos, nl)).replace(/\r$/, '')
      if (line.length > 0) out.push({ kind: 'line', text: line })
      pos = nl + 1
    }
    this.buf = this.buf.slice(pos)
    return out
  }
}
```

`app/src/main/viz.ts`:

```ts
import { FRAME_SPECTRUM } from '@shared/api'

/** Spectrum subscriptions by window (webContents id). The engine computes the spectrum only while
 * at least one window wants it (spec §3.6), and forgets the subscription when it restarts. */
export function createVizHub(opts: { call: (method: 'viz.subscribe' | 'viz.unsubscribe') => Promise<unknown>; send: (windowId: number, data: Uint8Array) => boolean }) {
  const subs = new Set<number>()
  let engineOn = false
  const sync = () => {
    const want = subs.size > 0
    if (want === engineOn) return
    engineOn = want
    // A failed subscribe (engine not ready) is retried by engineReady(); a failed unsubscribe means the engine is gone anyway.
    opts.call(want ? 'viz.subscribe' : 'viz.unsubscribe').catch(() => { engineOn = false })
  }
  return {
    set(windowId: number, on: boolean) { if (on) subs.add(windowId); else subs.delete(windowId); sync() },
    drop(windowId: number) { subs.delete(windowId); sync() },
    engineReady() { engineOn = false; sync() },
    frame(type: number, data: Uint8Array) {
      if (type !== FRAME_SPECTRUM) return
      for (const id of subs) opts.send(id, data)
    },
  }
}
```

```ts
    win.webContents.on('did-finish-load', relay.ready)
```

```ts
import { nativeImage, type NativeImage } from 'electron'

const AMBER = [0x47, 0xb5, 0xff, 0xff] // #FFB547 as BGRA
const DARK = [0x1a, 0x15, 0x17, 0xff] // #17151A as BGRA

/** BGRA pixels: a rounded amber square with a dark play triangle (drawn in code, so no asset to ship). */
export function trayIconPixels(size: number): Buffer {
  const px = Buffer.alloc(size * size * 4)
  const r = size * 0.22 // corner radius
  const inCorner = (x: number, y: number) => {
    const cx = x < r ? r : x > size - 1 - r ? size - 1 - r : x
    const cy = y < r ? r : y > size - 1 - r ? size - 1 - r : y
    return (x - cx) ** 2 + (y - cy) ** 2 > r * r
  }
  // Play triangle: points (0.36, 0.26), (0.36, 0.74), (0.74, 0.5) of the square.
  const inTriangle = (x: number, y: number) => {
    const u = (x + 0.5) / size, v = (y + 0.5) / size
    if (u < 0.36 || u > 0.74) return false
    const half = 0.24 * (1 - (u - 0.36) / 0.38)
    return Math.abs(v - 0.5) <= half
  }
  for (let y = 0; y < size; y++) {
    for (let x = 0; x < size; x++) {
      if (inCorner(x, y)) continue
      px.set(inTriangle(x, y) ? DARK : AMBER, (y * size + x) * 4)
    }
  }
  return px
}

export function trayIcon(): NativeImage {
  const img = nativeImage.createFromBitmap(trayIconPixels(16), { width: 16, height: 16, scaleFactor: 1 })
  img.addRepresentation({ scaleFactor: 2, width: 32, height: 32, buffer: trayIconPixels(32) })
  return img
}
```

```ts
import { trayIcon } from './trayIcon'

export type TrayState = { playing: boolean; mainVisible: boolean; miniOpen: boolean; title: string | null; artist: string | null }
export type TrayActions = { toggle(): void; next(): void; prev(): void; toggleMain(): void; toggleMini(): void; quit(): void }

export function trayMenuTemplate(s: TrayState, a: TrayActions): MenuItemConstructorOptions[] {
  return [
    { label: s.playing ? 'Pause' : 'Play', click: () => a.toggle() },
    { label: 'Next', click: () => a.next() },
    { label: 'Previous', click: () => a.prev() },
    { type: 'separator' },
    { label: s.mainVisible ? 'Hide Aurora' : 'Show Aurora', click: () => a.toggleMain() },
    { label: s.miniOpen ? 'Close mini-player' : 'Mini-player', click: () => a.toggleMini() },
    { type: 'separator' },
    { label: 'Quit Aurora', click: () => a.quit() },
  ]
}

export function trayTooltip(s: TrayState): string {
  if (!s.title) return 'Aurora'
  return s.artist ? `${s.title} — ${s.artist}` : s.title
}

/** The tray icon (spec §5.2). Call `update` whenever player state or window visibility changes. */
export function createTray(actions: TrayActions) {
  const tray = new Tray(trayIcon())
  let state: TrayState = { playing: false, mainVisible: true, miniOpen: false, title: null, artist: null }
  let shown = ''
  const render = () => {
    const key = JSON.stringify(state)
    if (key === shown) return
    shown = key
    tray.setToolTip(trayTooltip(state))
    tray.setContextMenu(Menu.buildFromTemplate(trayMenuTemplate(state, actions)))
  }
  if (process.platform !== 'darwin') tray.on('click', () => actions.toggleMain())
  render()
  return {
    update(patch: Partial<TrayState>) { state = { ...state, ...patch }; render() },
    destroy() { tray.destroy() },
  }
}
```

```ts
import { create } from 'zustand'
import type { DspState } from '@protocol/DspState'
import type { EqPreset } from '@protocol/EqPreset'
import type { ReplayGainMode } from '@protocol/ReplayGainMode'
import type { AuroraApi } from '@shared/api'
import { S } from '../lib/strings'
import { useUi } from './ui'

interface DspStore {
  api: AuroraApi | null
  state: DspState | null
  presets: EqPreset[]
  connect(api: AuroraApi): () => void
  setBand(i: number, db: number): Promise<void>
  setPreamp(db: number): Promise<void>
  setEnabled(on: boolean): Promise<void>
  applyPreset(name: string): Promise<void>
  savePreset(): Promise<void>
  deletePreset(): Promise<void>
  setCrossfade(secs: number): Promise<void>
  setReplayGain(mode: ReplayGainMode): Promise<void>
}

const message = (e: unknown) => (e instanceof Error ? e.message : String(e))

export const useDsp = create<DspStore>()((set, get) => {
  const load = async () => {
    const api = get().api
    if (!api) return
    try {
      const [state, presets] = await Promise.all([api.call('dsp.get', {}), api.call('dsp.presets', {})])
      set({ state, presets })
    } catch { /* engine not ready; engine.status → ready reloads */ }
  }
  /** Runs an engine call; on failure shows the error and reloads the engine's truth. */
  const run = async <T,>(p: (api: AuroraApi) => Promise<T>): Promise<T | null> => {
    const api = get().api
    if (!api) return null
    try { return await p(api) } catch (e) { useUi.getState().toast('error', message(e)); void load(); return null }
  }
  const sendEq = (bands: number[], preamp: number, preset?: string) => {
    const s = get().state
    if (s) set({ state: { ...s, eq: { ...s.eq, bands, preamp, preset: preset ?? null } } })
    return run((a) => a.call('dsp.setEq', preset ? { bands, preamp, preset } : { bands, preamp })).then(() => {})
  }
  return {
    api: null,
    state: null,
    presets: [],
    connect(api) {
      set({ api })
      const offs = [
        api.on('dsp.changed', (state) => set({ state })),
        api.on('engine.status', (s) => { if (s.state === 'ready') void load() }),
      ]
      void load()
      return () => offs.forEach((off) => off())
    },
    async setBand(i, db) {
      const s = get().state
      if (!s) return
      const bands = s.eq.bands.map((b, j) => (j === i ? db : b))
      await sendEq(bands, s.eq.preamp)
    },
    async setPreamp(db) { const s = get().state; if (s) await sendEq(s.eq.bands, db) },
    async setEnabled(on) {
      const s = get().state
      if (s) set({ state: { ...s, eq: { ...s.eq, enabled: on } } })
      await run((a) => a.call('dsp.setEqEnabled', { enabled: on }))
    },
    async applyPreset(name) {
      const p = get().presets.find((x) => x.name === name)
      if (p) await sendEq(p.bands, p.preamp, p.name)
    },
    async savePreset() {
      const name = await useUi.getState().askName({ title: S.savePresetTitle, confirm: S.save })
      if (!name) return
      if (await run((a) => a.call('dsp.savePreset', { name }))) await load()
    },
    async deletePreset() {
      const name = get().state?.eq.preset
      const p = get().presets.find((x) => x.name === name)
      if (!name || !p || p.builtin) return
      if (await run((a) => a.call('dsp.deletePreset', { name }))) await load()
    },
    async setCrossfade(secs) {
      const s = get().state
      if (s) set({ state: { ...s, crossfadeSecs: secs } })
      await run((a) => a.call('dsp.setCrossfade', { seconds: secs }))
    },
    async setReplayGain(mode) {
      const s = get().state
      if (s) set({ state: { ...s, replayGain: mode } })
      await run((a) => a.call('dsp.setReplayGain', { mode }))
    },
  }
})
```

```ts
import type { LyricLine } from '@protocol/LyricLine'
import type { LyricWord } from '@protocol/LyricWord'

function lastAtOrBefore<T>(items: T[], ms: number, t: (x: T) => number | undefined): number {
  let lo = 0, hi = items.length - 1, found = -1
  while (lo <= hi) {
    const mid = (lo + hi) >> 1
    const v = t(items[mid])
    if (v !== undefined && v <= ms) { found = mid; lo = mid + 1 } else hi = mid - 1
  }
  return found
}

/** Index of the line being sung at `ms` (lines are sorted by time), or -1 before the first. */
export const activeLine = (lines: LyricLine[], ms: number) => lastAtOrBefore(lines, ms, (l) => l.tMs ?? undefined)
export const activeWord = (words: LyricWord[], ms: number) => lastAtOrBefore(words, ms, (w) => w.tMs)
```

```ts
const FALL = 0.06 // max drop per frame, as a fraction of full scale

/** Next bar heights (0–1): rise instantly, fall gradually; with reduced motion, no smoothing. */
export function smooth(prev: Float32Array, next: Uint8Array, reduced: boolean): Float32Array {
  const out = new Float32Array(next.length)
  for (let i = 0; i < next.length; i++) {
    const v = next[i] / 255
    out[i] = reduced ? v : Math.max(v, (prev[i] ?? 0) - FALL)
  }
  return out
}
```

```tsx
import { useEffect, useRef } from 'react'
import { smooth } from '../lib/spectrum'
import { usePlayer } from '../stores/player'

const reducedMotion = () => typeof matchMedia === 'function' && matchMedia('(prefers-reduced-motion: reduce)').matches

/** 64-band spectrum (spec §3.6) drawn on a canvas. Subscribes only while mounted and visible. */
export function Spectrum({ className, height = 120 }: { className?: string; height?: number }) {
  const canvas = useRef<HTMLCanvasElement>(null)
  const api = usePlayer((p) => p.api)
  useEffect(() => {
    if (!api) return
    let bars = new Float32Array(64)
    let frames = 0
    let raf = 0
    const reduced = reducedMotion()
    const draw = () => {
      raf = 0
      const c = canvas.current
      const ctx = c?.getContext('2d')
      if (!c || !ctx) return
      const dpr = window.devicePixelRatio || 1
      const w = c.clientWidth * dpr, h = c.clientHeight * dpr
      if (c.width !== w || c.height !== h) { c.width = w; c.height = h }
      ctx.clearRect(0, 0, w, h)
      ctx.fillStyle = getComputedStyle(c).getPropertyValue('--accent').trim() || '#FFB547'
      const gap = 2 * dpr
      const bw = (w - gap * (bars.length - 1)) / bars.length
      bars.forEach((v, i) => { const bh = Math.max(dpr, v * h); ctx.fillRect(i * (bw + gap), h - bh, bw, bh) })
    }
    const off = api.onSpectrum((bins) => {
      bars = smooth(bars, bins, reduced)
      frames += 1
      if (canvas.current) canvas.current.dataset.frames = String(frames)
      if (!raf) raf = requestAnimationFrame(draw)
    })
    const sync = () => api.setViz(document.visibilityState !== 'hidden')
    sync()
    document.addEventListener('visibilitychange', sync)
    return () => {
      document.removeEventListener('visibilitychange', sync)
      off()
      api.setViz(false)
      if (raf) cancelAnimationFrame(raf)
    }
  }, [api])
  return <canvas ref={canvas} role="img" aria-label="Spectrum" className={className} style={{ width: '100%', height, display: 'block' }} data-frames="0" />
}
```

jsdom has no `requestAnimationFrame` in some setups. If the test environment lacks it, the frame counter still updates, because it's set before `requestAnimationFrame` is called. Guard with `typeof requestAnimationFrame === 'function'` if the test errors on it.

```ts
const channel = (c: number) => { const s = c / 255; return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4 }
const luminance = (hex: string) => {
  const n = parseInt(hex.replace('#', ''), 16)
  return 0.2126 * channel((n >> 16) & 255) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255)
}

/** WCAG 2.x contrast ratio between two #rrggbb colours. */
export function contrastRatio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x)
  return (hi + 0.05) / (lo + 0.05)
}

/** The accent to use for album art's vibrant colour: only when the setting is on and it reads ≥ 4.5:1 on the background (spec §5.5, §5.7). */
export function tintFor(vibrant: string | null | undefined, enabled: boolean, bg = '#17151A'): string | null {
  if (!enabled || !vibrant || !/^#[0-9a-f]{6}$/i.test(vibrant)) return null
  return contrastRatio(vibrant, bg) >= 4.5 ? vibrant : null
}

export function applyAccent(color: string | null) {
  const root = document.documentElement
  if (color) root.style.setProperty('--accent', color)
  else root.style.removeProperty('--accent')
}
```

```tsx
  const q = useEngineQuery(['track-info', trackId], (a) => a.call('library.track', { id: trackId }), [])
  const d = q.data
  if (!d) return null
  const t = d.track
  const rows: [string, string | null | undefined][] = [
    [S.credits.composer, d.composer], [S.credits.albumArtist, t.albumArtist], [S.credits.album, t.album], [S.credits.year, t.year?.toString()],
    [S.credits.genre, d.genres.map((g) => g.name).join(', ') || t.genre], [S.credits.track, t.trackNo ? `${t.trackNo}${d.trackTotal ? ` / ${d.trackTotal}` : ''}` : null],
    [S.credits.disc, t.discNo ? `${t.discNo}${d.discTotal ? ` / ${d.discTotal}` : ''}` : null],
    [S.credits.format, [t.codec?.toUpperCase(), t.bitDepth && `${t.bitDepth}-bit`, t.sampleRate && `${t.sampleRate / 1000} kHz`, t.bitrateKbps && `${t.bitrateKbps} kbps`].filter(Boolean).join(' · ')],
    [S.credits.file, t.path], [S.credits.mbRecording, d.musicbrainz.recording], [S.credits.mbRelease, d.musicbrainz.release],
  ]
  return (
    <dl className={s.credits}>
      {rows.filter(([, v]) => v).map(([k, v]) => <div key={k}><dt className="muted">{k}</dt><dd className={k === S.credits.format || k === S.credits.file ? 'mono' : undefined}>{v}</dd></div>)}
    </dl>
  )
}
```

```ts
import { expect, test } from '@playwright/test'
import { writeFileSync } from 'node:fs'
import { join } from 'node:path'
import { launchAurora, musicFolder, tempDir } from './fixture'

test('lyrics, visualizer, EQ in the signal path, and the mini-player', async () => {
  const musicDir = musicFolder(['flac16_44k.flac', 'short_a.flac'])
  writeFileSync(join(musicDir, 'flac16_44k.lrc'), '[00:00.00]Aurora sings\n[00:01.00]Second line\n')
  const { app, win } = await launchAurora({ dataDir: tempDir('aurora-data-'), musicDir, speed: 0.2 })
  try {
    await win.getByRole('button', { name: 'Add a music folder' }).click()
    await expect(win.getByRole('heading', { name: 'Recently added' })).toBeVisible({ timeout: 30_000 })
    await win.getByRole('link', { name: 'Albums' }).click()
    await win.getByRole('list', { name: 'Albums' }).getByText('Unknown album').click()
    await win.getByRole('button', { name: 'Play album' }).click()
    await expect(win.getByTestId('now-title')).toHaveText('flac16_44k')

    // Lyrics (Ctrl/Cmd+L) from the sidecar .lrc, with the visualizer receiving frames.
    await win.keyboard.press(process.platform === 'darwin' ? 'Meta+L' : 'Control+L')
    await expect(win.getByRole('tab', { name: 'Lyrics', selected: true })).toBeVisible()
    await expect(win.getByText('Aurora sings')).toBeVisible()
    await expect.poll(async () => Number(await win.getByRole('img', { name: 'Spectrum' }).getAttribute('data-frames')), { timeout: 10_000 }).toBeGreaterThan(3)

    // EQ: enable and pick a preset in Settings; the signal path names it.
    await win.getByRole('link', { name: 'Settings' }).click()
    const eq = win.getByRole('group', { name: 'Equalizer' })
    await eq.getByRole('switch', { name: 'Equalizer' }).click()
    await eq.getByRole('combobox', { name: 'EQ preset' }).selectOption('Bass')
    await win.getByRole('link', { name: 'Signal path' }).click()
    await expect(win.getByText('Bass')).toBeVisible()

    // Mini-player (Ctrl/Cmd+M): a second, always-on-top window showing the track.
    const [mini] = await Promise.all([app.waitForEvent('window'), win.keyboard.press(process.platform === 'darwin' ? 'Meta+M' : 'Control+M')])
    await expect(mini.getByText('flac16_44k')).toBeVisible()
    expect(await app.evaluate(({ BrowserWindow }) => BrowserWindow.getAllWindows().find((w) => w.getTitle().includes('mini'))?.isAlwaysOnTop())).toBe(true)
    await mini.getByRole('button', { name: 'Pause' }).click()
    await expect(win.getByRole('button', { name: 'Play', exact: true })).toBeVisible()
    await mini.getByRole('button', { name: 'Close mini-player' }).click()
    await expect.poll(() => app.windows().length).toBe(1)
  } finally {
    await app.close()
  }
})
```
