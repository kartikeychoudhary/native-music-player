# Aurora M4 — Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Aurora shippable:
- CI-built installers for Windows, macOS and Linux on x64 and arm64.
- A no-fdk-aac variant.
- Auto-update from GitHub Releases.
- Optional code signing.
- A bundled third-party license file.
- An About section.
- The two engine robustness fixes that M3 deferred to this milestone.

**Architecture:**
- **Release workflow** (`.github/workflows/release.yml`), triggered by a `v*` tag:
  - builds the Rust engine natively on six runners, both with and without the `fdk-aac` feature, and checks its linked libraries and handshake;
  - packages each OS once for both architectures with electron-builder;
  - smoke-tests the packaged app;
  - creates a **draft** GitHub release. A human publishes it after the manual test matrix.
- **The packaged app** finds the engine at `resources/bin/<platform>-<arch>/` (the existing `enginePath`) and reads `resources/build-info.json` to learn its variant. It picks an update mode from how it was installed:
  - **auto:** electron-updater downloads, and the update installs on restart or quit. Used by NSIS, AppImage and signed macOS builds.
  - **notify:** a GitHub API check that links to the release page. Used by the portable zip, deb/rpm, unsigned macOS and no-fdk builds.
- **Build tooling** is plain TypeScript that Node 24 runs directly (type stripping), kept in `app/build-tools/`, with its pure logic unit-tested by Vitest.

**Tech Stack:**
- Unchanged: Rust 1.99.0, Electron 44.7.0, React 19.3, Zustand 5, Vitest 5, Playwright 1.64.
- New npm packages, pinned exactly:
  - `electron-builder` (dev);
  - `electron-updater` (runtime);
  - `yaml` (dev, for the workflow lint test).
- New Rust: only the `Win32_UI_Shell` and `Win32_System_Com` features of the existing `windows` crate.

**Spec:** `docs/superpowers/specs/2026-10-10-aurora-music-player-design.md`. This plan implements **Milestone 4** from §9 and closes the "Deferred to M4" items in `docs/superpowers/m3-execution-notes.md`. - **Standard variant (with fdk-aac):**

## Review Focus

1. **Missing VC++ runtime.** On a fresh Windows machine without the Visual C++ redistributable, the engine must still start. Pinned by Task 8:
   - `+crt-static`;
   - `check-engine-deps.sh` fails on any `VCRUNTIME*`, `MSVCP*` or `api-ms-win-crt-*` import;
   - the release workflow runs it on both Windows targets.
2. **Executable bit.** The engine must stay executable through CI artifacts, because upload-artifact drops the executable bit on Linux and macOS. Pinned by:
   - Task 10 tars the staged engines before upload;
   - Task 8's `afterPack` hook `chmod 755`s the engine in every packed app;
   - the packaged smoke test fails on a spawn error.
3. **Offline, rate-limited or GitHub down.** A failing update check must not:
   - show a banner;
   - throw;
   - replace a known "available" state with an error.
   Only a manual **Check now** shows the error. Pinned by Task 9 controller tests.
4. **Wrong variant or install kind.** No-fdk, zip, deb/rpm and unsigned macOS builds must never download and install an update. Those builds only link to the release page. Pinned by Task 9 `updateMode` tests.
5. **Update ready while music plays.** Nothing restarts until the user clicks **Restart now**. When they do, the engine is stopped first, so the installer can replace `aurora-engine.exe`. Pinned by Task 9 controller tests (`install` is a no-op unless the state is `ready`, and it awaits `beforeInstall`).

### Task 1: Crossfade tail streams instead of buffering

M3 buffered the outgoing track's whole remaining output (`Crossfade::tail: Vec<f64>`) before mixing. That is about 13 s, and it grows without bound when a decoder's `total_frames` underestimates the real length. Only the last `planned` frames can be part of the overlap. Everything older is written unmixed as soon as it is decoded.

**Files:**
- Create: `engine/crates/engine-core/src/player/tail.rs`
- Modify: `engine/crates/engine-core/src/player/mod.rs`:
  - add `mod tail;`;
  - in `struct Crossfade`, change `tail: Vec<f64>` to `tail: TailBuffer`;
  - update `maybe_start_crossfade`'s constructor;
  - update `crossfade_step`, and every other `x.tail` / `.tail` use on a `Crossfade` (find them with `grep -n "\.tail\b" engine/crates/engine-core/src/player/mod.rs`).

**Interfaces:**
- Produces (crate-private): `TailBuffer::new(channels: usize, keep_frames: usize)`, `push(&mut self, samples: &[f64]) -> Vec<f64>`, `frames(&self) -> usize`, `samples(&self) -> &[f64]`.

```rust
//! The outgoing track's tail during a crossfade. Only its last `keep` frames can fall inside the
//! overlap, so anything older is handed back by `push` to be written unmixed at once. This bounds
//! memory to the overlap however long the track really is (M3 final review F4).

/// Interleaved f64 frames, at most `keep` of them (plus nothing: excess is returned by `push`).
pub struct TailBuffer { ch: usize, keep: usize, buf: Vec<f64> }

#[cfg(test)]
mod tests {
    use super::TailBuffer;

    fn ramp(from: usize, frames: usize, ch: usize) -> Vec<f64> {
        (from * ch..(from + frames) * ch).map(|i| i as f64).collect()
    }

    #[test]
    fn never_holds_more_than_the_overlap_and_loses_nothing() {
        let (ch, keep, block) = (2, 100, 64);
        let mut t = TailBuffer::new(ch, keep);
        let mut out = Vec::new();
        for b in 0..50 {
            out.extend(t.push(&ramp(b * block, block, ch)));
            assert!(t.frames() <= keep, "block {b}: {} frames held", t.frames());
        }
        out.extend_from_slice(t.samples());
        assert_eq!(out, ramp(0, 50 * block, ch), "every sample, in order, exactly once");
        assert_eq!(t.frames(), keep);
    }

    #[test]
    fn a_tail_shorter_than_the_overlap_is_kept_whole() {
        let mut t = TailBuffer::new(2, 100);
        assert!(t.push(&ramp(0, 30, 2)).is_empty());
        assert_eq!(t.frames(), 30);
        assert_eq!(t.samples(), &ramp(0, 30, 2)[..]);
    }

    #[test]
    fn returns_whole_frames_only() {
        let mut t = TailBuffer::new(3, 4);
        let early = t.push(&ramp(0, 10, 3));
        assert_eq!(early.len() % 3, 0);
        assert_eq!(early, ramp(0, 6, 3));
    }
}
```

```rust
impl TailBuffer {
    pub fn new(channels: usize, keep_frames: usize) -> Self { Self { ch: channels.max(1), keep: keep_frames, buf: Vec::new() } }

    /// Appends rendered samples and returns the frames that can no longer be part of the overlap.
    pub fn push(&mut self, samples: &[f64]) -> Vec<f64> {
        self.buf.extend_from_slice(samples);
        let frames = self.buf.len() / self.ch;
        if frames <= self.keep { return Vec::new(); }
        self.buf.drain(..(frames - self.keep) * self.ch).collect()
    }

    pub fn frames(&self) -> usize { self.buf.len() / self.ch }
    pub fn samples(&self) -> &[f64] { &self.buf }
}
```

### Task 2: Library calls that read audio files run off the stdin thread

Two calls do file I/O on the RPC thread:
- `lyrics.get` reads a sidecar `.lrc` and parses tags;
- `library.track` opens a decoder to read the gapless info.

On a slow disk or network share, either one stalls every later command, including play and pause, until it returns (M3 final review F8). Both now run on one worker thread. Replies are written when ready, and the client already matches responses by id.

```rust
//! Runs library calls that touch audio files (`lyrics.get`, `library.track`) off the stdin thread, so
//! a slow disk or network share can't hold up player commands. A reply is written when its job is
//! done; clients match responses by id, so it may overtake earlier requests' replies.

use std::thread::JoinHandle;

use crossbeam_channel::{unbounded, Sender};
use serde_json::Value;

const SLOW_METHODS: [&str; 2] = ["lyrics.get", "library.track"];

pub fn is_slow(method: &str) -> bool { SLOW_METHODS.contains(&method) }

pub struct Job { pub id: Value, pub method: String, pub params: Value }

pub struct IoWorker { tx: Option<Sender<Job>>, handle: Option<JoinHandle<()>> }

impl IoWorker {
    /// `handle` runs each job on the worker thread and writes its response.
    pub fn spawn(handle: impl Fn(Job) + Send + 'static) -> Self {
        let (tx, rx) = unbounded::<Job>();
        let h = std::thread::Builder::new().name("aurora-io".into()).spawn(move || { for job in rx { handle(job) } }).expect("spawn io worker");
        Self { tx: Some(tx), handle: Some(h) }
    }

    pub fn submit(&self, job: Job) { if let Some(tx) = &self.tx { let _ = tx.send(job); } }

    /// Lets queued jobs finish (their replies are still written), then stops the thread.
    pub fn shutdown(&mut self) {
        self.tx.take();
        if let Some(h) = self.handle.take() { let _ = h.join(); }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::sync::{Arc, Mutex};

    #[test]
    fn only_file_touching_library_calls_are_slow() {
        assert!(is_slow("lyrics.get") && is_slow("library.track"));
        assert!(!is_slow("library.tracks") && !is_slow("player.state") && !is_slow("playlists.get"));
    }

    #[test]
    fn shutdown_finishes_queued_jobs() {
        let done = Arc::new(Mutex::new(Vec::new()));
        let d = done.clone();
        let mut w = IoWorker::spawn(move |j| d.lock().unwrap().push(j.id));
        for i in 0..3 { w.submit(Job { id: i.into(), method: "lyrics.get".into(), params: Value::Null }); }
        w.shutdown();
        assert_eq!(*done.lock().unwrap(), vec![Value::from(0), 1.into(), 2.into()]);
    }
}
```

```ts
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'

/** The repository root (app/build-tools/../..). */
export const REPO_ROOT = resolve(dirname(fileURLToPath(import.meta.url)), '../..')

export const SEMVER = /^\d+\.\d+\.\d+(-[0-9A-Za-z.-]+)?$/

const SECTION = /^\[workspace\.package\]\s*$([\s\S]*?)(?=^\[|(?![\s\S]))/m
const VERSION = /^version\s*=\s*"([^"]*)"/m

export function engineVersion(cargoToml: string): string | null {
  const section = SECTION.exec(cargoToml)?.[1]
  return section ? VERSION.exec(section)?.[1] ?? null : null
}

export function setEngineVersion(cargoToml: string, v: string): string {
  return cargoToml.replace(SECTION, (section) => section.replace(VERSION, `version = "${v}"`))
}

export function checkVersions(o: { app: string; engine: string | null; tag?: string }): string[] {
  const problems: string[] = []
  if (!SEMVER.test(o.app)) problems.push(`app/package.json version "${o.app}" is not semver`)
  if (o.engine === null) problems.push('engine/Cargo.toml has no [workspace.package] version')
  else if (o.engine !== o.app) problems.push(`app/package.json has ${o.app} but engine/Cargo.toml has ${o.engine}`)
  if (o.tag !== undefined && o.tag !== `v${o.app}`) problems.push(`tag ${o.tag} does not match version ${o.app}`)
  return problems
}
```

```ts
import { readFileSync } from 'node:fs'
import { join } from 'node:path'

/** Written by app/build-tools/build-info.ts and packaged as resources/build-info.json. */
export interface BuildInfo { variant: 'standard' | 'nofdk'; macSigned: boolean; commit: string | null }

export const DEV_BUILD: BuildInfo = Object.freeze({ variant: 'standard', macSigned: false, commit: null })

export function parseBuildInfo(raw: unknown): BuildInfo {
  if (typeof raw !== 'object' || raw === null) return DEV_BUILD
  const r = raw as Record<string, unknown>
  if ((r.variant !== 'standard' && r.variant !== 'nofdk') || typeof r.macSigned !== 'boolean' || (r.commit !== null && typeof r.commit !== 'string')) return DEV_BUILD
  return { variant: r.variant, macSigned: r.macSigned, commit: r.commit }
}

export function readBuildInfo(o: { isPackaged: boolean; resourcesPath: string; read?: (p: string) => string }): BuildInfo {
  if (!o.isPackaged) return DEV_BUILD
  try { return parseBuildInfo(JSON.parse((o.read ?? ((p) => readFileSync(p, 'utf8')))(join(o.resourcesPath, 'build-info.json')))) } catch { return DEV_BUILD }
}
```

```ts
import { crc32, deflateSync } from 'node:zlib'

function chunk(type: string, data: Buffer): Buffer {
  const len = Buffer.alloc(4); len.writeUInt32BE(data.length)
  const body = Buffer.concat([Buffer.from(type, 'ascii'), data])
  const crc = Buffer.alloc(4); crc.writeUInt32BE(crc32(body))
  return Buffer.concat([len, body, crc])
}

/** An 8-bit RGBA PNG from BGRA pixels (Electron's bitmap order). */
export function encodePng(width: number, height: number, bgra: Uint8Array): Buffer {
  const raw = Buffer.alloc(height * (width * 4 + 1))
  for (let y = 0; y < height; y++) {
    const row = y * (width * 4 + 1)
    for (let x = 0; x < width; x++) {
      const i = (y * width + x) * 4, o = row + 1 + x * 4
      raw[o] = bgra[i + 2]; raw[o + 1] = bgra[i + 1]; raw[o + 2] = bgra[i]; raw[o + 3] = bgra[i + 3]
    }
  }
  const ihdr = Buffer.alloc(13)
  ihdr.writeUInt32BE(width, 0); ihdr.writeUInt32BE(height, 4); ihdr[8] = 8; ihdr[9] = 6
  return Buffer.concat([Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]), chunk('IHDR', ihdr), chunk('IDAT', deflateSync(raw, { level: 9 })), chunk('IEND', Buffer.alloc(0))])
}
```

```ts
import { mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { join } from 'node:path'
import type { Plugin } from 'vite'
import { REPO_ROOT } from './versions.ts'

/** The npm package a bundled module id belongs to (the innermost node_modules entry), or null. */
export function packageOf(id: string): { name: string; dir: string } | null {
  const p = id.replace(/\\/g, '/')
  const at = p.lastIndexOf('/node_modules/')
  if (id.startsWith('\0') || at < 0) return null
  const rest = p.slice(at + '/node_modules/'.length).split('/')
  const name = rest[0].startsWith('@') ? `${rest[0]}/${rest[1]}` : rest[0]
  return { name, dir: `${p.slice(0, at)}/node_modules/${name}` }
}

/** Records which npm packages ended up in this build (for THIRD_PARTY_LICENSES.txt). */
export function bundledPackages(target: 'main' | 'preload' | 'renderer'): Plugin {
  return {
    name: 'aurora-bundled-packages',
    apply: 'build',
    generateBundle() {
      const seen = new Map<string, { name: string; version: string; license: string | null; dir: string }>()
      for (const id of this.getModuleIds()) {
        const pkg = packageOf(id)
        if (!pkg || seen.has(pkg.dir)) continue
        const json = JSON.parse(readFileSync(join(pkg.dir, 'package.json'), 'utf8')) as { version: string; license?: unknown }
        seen.set(pkg.dir, { ...pkg, version: json.version, license: typeof json.license === 'string' ? json.license : null })
      }
      const out = join(REPO_ROOT, 'app/build/generated')
      mkdirSync(out, { recursive: true })
      writeFileSync(join(out, `bundled-${target}.json`), JSON.stringify([...seen.values()].sort((a, b) => a.name.localeCompare(b.name)), null, 2))
    },
  }
}
```

```ts
/** Crates that must contribute at least one license text (vendored C code we redistribute). */
export const REQUIRED_TEXTS = ['audiopus_sys', 'libsqlite3-sys', 'libwebp-sys']
export const REQUIRED_TEXTS_FDK = ['fdk-aac-sys']

const TEXT_FILE = /^(licen[cs]e|copying|notice|copyright|unlicense)([.-].*)?$/i

export function licenseOk(expr: string | null): boolean {
  if (!expr) return false
  const e = expr.trim().replace(/\s*\/\s*/g, ' OR ')
  // Split on top-level OR, then AND; parentheses are evaluated recursively.
  const strip = (s: string) => { s = s.trim(); while (s.startsWith('(') && s.endsWith(')') && balanced(s.slice(1, -1))) s = s.slice(1, -1).trim(); return s }
  const balanced = (s: string) => { let d = 0; for (const c of s) { if (c === '(') d++; if (c === ')' && --d < 0) return false } return d === 0 }
  const split = (s: string, op: string) => { const parts: string[] = []; let d = 0, start = 0; const re = new RegExp(`\\s${op}\\s`, 'y'); for (let i = 0; i < s.length; i++) { if (s[i] === '(') d++; else if (s[i] === ')') d--; else if (d === 0) { re.lastIndex = i; const m = re.exec(s); if (m) { parts.push(s.slice(start, i)); start = i + m[0].length; i = start - 1 } } } parts.push(s.slice(start)); return parts }
  const ok = (s: string): boolean => {
    s = strip(s)
    const ors = split(s, 'OR'); if (ors.length > 1) return ors.some(ok)
    const ands = split(s, 'AND'); if (ands.length > 1) return ands.every(ok)
    return ALLOWED.has(s)
  }
  return ok(e)
}

export function cargoComponents(meta: CargoMetadata, readTexts: (dir: string, extra?: string[]) => LicenseText[]): Component[] {
  const byId = new Map(meta.packages.map((p) => [p.id, p]))
  const nodes = new Map(meta.resolve.nodes.map((n) => [n.id, n]))
  const seen = new Set<string>(), out: Component[] = []
  const walk = (id: string) => {
    if (seen.has(id)) return
    seen.add(id)
    const pkg = byId.get(id)!
    if (pkg.source !== null) {
      const license = LICENSE_OVERRIDES[pkg.name] ?? pkg.license
      out.push({ source: 'cargo', name: pkg.name, version: pkg.version, license, texts: readTexts(dirname(pkg.manifest_path), EXTRA_TEXTS[pkg.name]) })
    }
    for (const d of nodes.get(id)?.deps ?? []) if (d.dep_kinds.some((k) => k.kind === null)) walk(d.pkg)
  }
  if (meta.resolve.root) walk(meta.resolve.root)
  return out.sort((a, b) => a.name.localeCompare(b.name) || a.version.localeCompare(b.version))
}

export function npmComponents(pkgs: NpmPackage[], readTexts: (dir: string) => LicenseText[]): Component[] {
  const out = new Map<string, Component>()
  for (const p of pkgs) { const k = `${p.name}@${p.version}`; if (!out.has(k)) out.set(k, { source: 'npm', name: p.name, version: p.version, license: p.license, texts: readTexts(p.dir) }) }
  return [...out.values()].sort((a, b) => a.name.localeCompare(b.name))
}

export function render(components: Component[]): string {
  const head = 'Aurora includes the following third-party software. Each component is listed with its license\nand the license texts its authors ship. Electron and Chromium licenses are in LICENSES.chromium.html\nnext to the Aurora executable.\n'
  const body = components.map((c) => [
    '='.repeat(78), `${c.name} ${c.version} (${c.source === 'cargo' ? 'Rust crate' : 'npm package'})`, `License: ${c.license ?? 'see text below'}`, '',
    ...c.texts.flatMap((t) => [`--- ${t.file} ---`, t.text.trim(), '']),
  ].join('\n'))
  return `${head}\n${body.join('\n')}\n`
}

export function readTexts(dir: string, extra: string[] = []): LicenseText[] {
  const files = existsSync(dir) ? readdirSync(dir).filter((f) => TEXT_FILE.test(f)).sort() : []
  return [...files, ...extra].filter((f) => existsSync(join(dir, f))).map((f) => ({ file: f, text: readFileSync(join(dir, f), 'utf8') }))
}
```

```js
// electron-builder afterPack hook: every packed app must contain its arch's engine, executable
// (artifact round-trips can drop the exec bit). electron-builder requires this file, so it is CommonJS.
const { chmodSync, existsSync } = require('node:fs')
const { join } = require('node:path')

const ARCH = { 0: 'ia32', 1: 'x64', 2: 'armv7l', 3: 'arm64', 4: 'universal' } // builder-util's Arch enum

function enginePathInApp(appOutDir, platform, arch, productFilename) {
  const resources = platform === 'darwin' ? join(appOutDir, `${productFilename}.app`, 'Contents', 'Resources') : join(appOutDir, 'resources')
  return join(resources, 'bin', `${platform}-${arch}`, platform === 'win32' ? 'aurora-engine.exe' : 'aurora-engine')
}

async function afterPack(ctx) {
  const arch = ARCH[ctx.arch] ?? String(ctx.arch)
  const engine = enginePathInApp(ctx.appOutDir, ctx.electronPlatformName, arch, ctx.packager.appInfo.productFilename)
  if (!existsSync(engine)) throw new Error(`no engine for ${ctx.electronPlatformName}-${arch} at ${engine} (stage it with app/build-tools/stage-engine.ts)`)
  chmodSync(engine, 0o755)
}

module.exports = afterPack
module.exports.default = afterPack
module.exports.enginePathInApp = enginePathInApp
```

```bash
#!/usr/bin/env bash
# Usage: check-engine-deps.sh <engine binary> <windows|macos|linux>
# Fails if the engine links a library a user's machine may not have. Needs llvm-objdump from the
# Rust toolchain: `rustup component add llvm-tools`.
set -euo pipefail
bin="$1"; os="$2"
objdump="$(find "$(rustc --print sysroot)" -name 'llvm-objdump*' -type f | head -n 1)"
[ -x "$objdump" ] || { echo "llvm-objdump not found: rustup component add llvm-tools"; exit 2; }
case "$os" in
  windows) libs=$("$objdump" -p "$bin" | sed -n 's/^ *DLL Name: //p')
           bad=$(echo "$libs" | grep -iE '^(vcruntime|msvcp|api-ms-win-crt-)' || true) ;;
  macos)   libs=$("$objdump" --macho --dylibs-used "$bin" | tail -n +2 | awk '{print $1}')
           bad=$(echo "$libs" | grep -vE '^(/usr/lib/|/System/Library/)' || true) ;;
  linux)   libs=$("$objdump" -p "$bin" | sed -n 's/^ *NEEDED *//p')
           bad=$(echo "$libs" | grep -vE '^(libc|libm|libdl|librt|libpthread|libgcc_s|ld-linux[-.a-z0-9_]*|libasound|libpipewire-0\.3)\.so' || true) ;;
  *) echo "unknown os $os"; exit 2 ;;
esac
echo "$bin links:"; echo "$libs" | sed 's/^/  /'
if [ -n "$bad" ]; then echo "not allowed:"; echo "$bad" | sed 's/^/  /'; exit 1; fi
```

```ts
import type { BuildInfo } from './buildInfo'
import type { InstallKind } from './installKind'
import type { UpdateMode, UpdateState } from '@shared/api'

export type { UpdateMode, UpdateState }

export const RELEASES = { owner: 'kartikeychoudhary', repo: 'native-music-player' } as const
export const FIRST_CHECK_MS = 10_000
export const CHECK_EVERY_MS = 6 * 60 * 60 * 1000

/** Which builds install updates themselves; everything else only links to the release page. */
export function updateMode(kind: InstallKind, build: BuildInfo): UpdateMode {
  if (kind === 'dev') return 'off'
  if (build.variant === 'nofdk') return 'notify' // the update feed is the standard variant's
  if (kind === 'nsis' || kind === 'appimage') return 'auto'
  if (kind === 'mac') return build.macSigned ? 'auto' : 'notify' // Squirrel.Mac needs a signed app
  return 'notify'
}

const SEMVER = /^(\d+)\.(\d+)\.(\d+)(?:-([0-9A-Za-z.-]+))?$/

export function isNewer(candidate: string, current: string): boolean {
  const a = SEMVER.exec(candidate), b = SEMVER.exec(current)
  if (!a || !b) return false
  for (let i = 1; i <= 3; i++) { const d = Number(a[i]) - Number(b[i]); if (d) return d > 0 }
  if (!a[4] || !b[4]) return !a[4] && !!b[4] // a release beats its prereleases
  return a[4].localeCompare(b[4], 'en', { numeric: true }) > 0
}

export function releaseUrl(version: string): string {
  return `https://github.com/${RELEASES.owner}/${RELEASES.repo}/releases/tag/v${version}`
}

/** The newest published (not draft, not prerelease) version on GitHub, or null if there is none. */
export async function latestPublishedVersion(fetchFn: typeof fetch): Promise<string | null> {
  const r = await fetchFn(`https://api.github.com/repos/${RELEASES.owner}/${RELEASES.repo}/releases/latest`, { headers: { Accept: 'application/vnd.github+json', 'User-Agent': 'Aurora' } })
  if (r.status === 404) return null
  if (!r.ok) throw new Error(`GitHub answered ${r.status}`)
  const j = (await r.json()) as { tag_name?: unknown }
  return typeof j.tag_name === 'string' ? j.tag_name.replace(/^v/, '') : null
}

/** The slice of electron-updater's AppUpdater this module uses. */
export interface AutoUpdaterLike {
  autoDownload: boolean
  autoInstallOnAppQuit: boolean
  on(event: string, cb: (arg: never) => void): unknown
  checkForUpdates(): Promise<unknown>
  quitAndInstall(isSilent?: boolean, isForceRunAfter?: boolean): void
}

export interface ControllerDeps {
  mode: UpdateMode
  currentVersion: string
  /** Whether automatic checks are on (Settings); manual checks ignore it. */
  enabled: () => boolean
  autoUpdater: () => AutoUpdaterLike
  latestVersion: () => Promise<string | null>
  /** Stops the engine so the installer can replace its binary. */
  beforeInstall: () => Promise<void>
  onState: (s: UpdateState) => void
  setTimer: (fn: () => void, ms: number) => unknown
  setRepeat: (fn: () => void, ms: number) => unknown
}

const message = (e: unknown) => (e instanceof Error ? e.message : String(e))

export function createUpdateController(d: ControllerDeps) {
  let state: UpdateState = { status: 'idle' }
  let before: UpdateState = state
  let manual = false
  let au: AutoUpdaterLike | null = null
  const set = (s: UpdateState) => { state = s; d.onState(s) }
  const fail = (e: unknown) => {
    if (state.status !== 'checking' && state.status !== 'downloading') return
    set(manual ? { status: 'error', message: message(e) } : before)
  }
  const updater = () => {
    if (au) return au
    au = d.autoUpdater()
    au.autoDownload = true
    au.autoInstallOnAppQuit = true
    au.on('update-available', (i: { version: string }) => set({ status: 'downloading', version: i.version, percent: 0 }))
    au.on('download-progress', (p: { percent: number }) => { if (state.status === 'downloading') set({ ...state, percent: Math.round(p.percent) }) })
    au.on('update-downloaded', (i: { version: string }) => set({ status: 'ready', version: i.version }))
    au.on('update-not-available', () => { if (state.status === 'checking') set({ status: 'current' }) })
    au.on('error', (e: unknown) => fail(e))
    return au
  }
  async function check(isManual: boolean) {
    if (d.mode === 'off' || ['checking', 'downloading', 'ready'].includes(state.status)) return
    if (!isManual && !d.enabled()) return
    manual = isManual
    before = state
    set({ status: 'checking' })
    try {
      if (d.mode === 'auto') {
        await updater().checkForUpdates()
        // electron-updater emits its events before resolving; one that resolved silently (inactive updater) found nothing.
        if (state.status === 'checking') set({ status: 'current' })
      } else {
        const v = await d.latestVersion()
        set(v && isNewer(v, d.currentVersion) ? { status: 'available', version: v } : { status: 'current' })
      }
    } catch (e) { fail(e) }
  }
  return {
    get state() { return state },
    start() {
      if (d.mode === 'off') return
      d.setTimer(() => void check(false), FIRST_CHECK_MS)
      d.setRepeat(() => void check(false), CHECK_EVERY_MS)
    },
    check: () => check(true),
    async install() {
      if (state.status !== 'ready' || !au) return
      await d.beforeInstall()
      au.quitAndInstall(true, true)
    },
  }
}
```

```ts
import { execFileSync } from 'node:child_process'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'
import { stageEngine } from './stage-engine.ts'
import { REPO_ROOT } from './versions.ts'

type Platform = 'win32' | 'darwin' | 'linux'
export const TRIPLES: Record<Platform, { x64: string; arm64: string }> = {
  win32: { x64: 'x86_64-pc-windows-msvc', arm64: 'aarch64-pc-windows-msvc' },
  darwin: { x64: 'x86_64-apple-darwin', arm64: 'aarch64-apple-darwin' },
  linux: { x64: 'x86_64-unknown-linux-gnu', arm64: 'aarch64-unknown-linux-gnu' },
}
const FLAG: Record<Platform, string> = { win32: '--win', darwin: '--mac', linux: '--linux' }
const PORTABLE: Record<Platform, string> = { win32: 'zip', darwin: 'zip', linux: 'tar.gz' }

export function builderArgs(o: { platform: Platform; variant: 'standard' | 'nofdk'; signed: boolean }): string[] {
  const args = o.variant === 'standard'
    ? [FLAG[o.platform], '--x64', '--arm64', '--publish', 'never']
    : [FLAG[o.platform], PORTABLE[o.platform], '--x64', '--arm64', '--publish', 'never', '-c.directories.output=dist-nofdk', '-c.artifactName=${productName}-${version}-${os}-${arch}-nofdk.${ext}']
  if (o.platform === 'darwin' && !o.signed) args.push('-c.mac.identity=-') // ad-hoc: arm64 macOS refuses unsigned code
  return args
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const platform = process.argv[process.argv.indexOf('--platform') + 1] as Platform
  if (!(platform in TRIPLES)) { console.error('usage: package-ci.ts --platform win32|darwin|linux [--signed]'); process.exit(2) }
  const signed = process.argv.includes('--signed')
  const app = join(REPO_ROOT, 'app')
  const sh = process.platform === 'win32'
  const node = (script: string, ...a: string[]) => execFileSync(process.execPath, [join(app, 'build-tools', script), ...a], { stdio: 'inherit' })
  const npx = (...a: string[]) => execFileSync('npx', a, { cwd: app, stdio: 'inherit', shell: sh })
  const exe = platform === 'win32' ? 'aurora-engine.exe' : 'aurora-engine'
  const targets = Object.values(TRIPLES[platform]).flatMap((t) => ['--target', t])
  npx('electron-vite', 'build')
  for (const variant of ['standard', 'nofdk'] as const) {
    for (const arch of ['x64', 'arm64'] as const) stageEngine({ src: join(REPO_ROOT, 'engines', arch, variant, exe), appRoot: app, platform, arch })
    node('licenses.ts', ...targets, ...(variant === 'nofdk' ? ['--no-fdk'] : []))
    node('build-info.ts', '--variant', variant, ...(platform === 'darwin' && signed ? ['--mac-signed'] : []))
    npx('electron-builder', ...builderArgs({ platform, variant, signed }))
  }
}
```
